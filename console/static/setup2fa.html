Turn on two-factor sign-in

This is required once, before the panel opens. After this, every sign-in asks for your password and a 6-digit code from your phone.
  1. Install an authenticator app if you have none: Google Authenticator, Microsoft Authenticator, 1Password, Bitwarden, Aegis or Authy.
  2. In the app choose add account and scan this code.
  3. Type the 6-digit code it shows, then press the button.

Save your recovery codes

    
If you lose your phone, each of these codes signs you in once instead of the 6-digit code. They are shown only now. Keep them somewhere safe and offline, such as a password manager.
