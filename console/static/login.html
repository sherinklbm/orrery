Capabilities

Everything runs on your server.

01

Any model, any provider

Use hosted or open models from any compatible provider. Browse the full catalogue and pick from a list, with prices and context sizes.

02

Ordered failover

Set a first choice and as many backups as you like. When a model is down or out of credit, the next one answers automatically.

03

Per-client routing

The agent and the workflows each get their own model order and their own private gateway token.

04

Personal AI agent

An assistant you message from your phone, with the server permissions you decide to grant it, and nothing more.

05

Workflow automation

A visual workflow builder on its own subdomain, wired to the same gateway so every workflow can use your models.

06

MCP tools in one click

Link your workflows to the agent as tools, and add vetted MCP servers from a curated catalogue without editing files.

07

Desktop app link

A permanent, private link for the desktop app over your own mesh network. No tunnels, and it survives restarts.

08

Two-factor sign-in

Time-based codes from any authenticator app, required from the first login, with one-time recovery codes.

09

Hardened by default

Firewall, automatic security updates, kernel hardening, optional brute-force bans and strict browser security headers.

10

Self-test and backups

One command checks every part and prints pass or fail. Nightly backups, and the whole stack comes back after a reboot.

11

One-command install

A fresh Ubuntu or Debian server, or any computer with Docker, is running in minutes. Updates are one command too.

12

Open source

MIT licensed, standard-library code you can read in an afternoon. No telemetry, no accounts, no lock-in.
