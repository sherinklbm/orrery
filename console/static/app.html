    Model order: main and backups

    The main model is the one you saved above. If it fails (out of credit, rate-limited, down, or the model was withdrawn), the gateway automatically tries the next one: second, third and so on. A backup can be on a different provider, as long as a key is saved for that provider. A model that just failed is tried last for a minute, so a dead main model does not slow every answer.

        How it works

        • Hermes and n8n both send their AI requests to a small gateway on your server. The gateway reads this page's choice and uses it, so a change here applies to both within about 15 seconds.
        • Keys are stored on your server, are never shown again after saving, and are not visible to Hermes or n8n. They are not encrypted at rest, so use a dedicated key with a spending limit.
        • Anthropic, OpenAI, Google Gemini, NVIDIA, OpenRouter, DeepSeek, Groq, Mistral and more are listed. Use "Custom" for anything else with an OpenAI-compatible API.

        Recent changes

          1. n8n API key

          In n8n: Settings → n8n API → Create an API key, then paste it here. It lets this panel create the link for you, so you do not build anything in n8n by hand. Open n8n

          2. Connect Hermes and n8n

          Creates a protected tool workflow in n8n, gives Hermes the matching secret, adds n8n to Hermes's tools and tests the link. Safe to press again.

            3. Let n8n use an AI provider

            Creates an “OpenAI API” credential in n8n that points at your AI gateway. In any workflow add an OpenAI Chat Model node and pick Orrery AI gateway (n8n). Which provider n8n gets (the same as Hermes, or its own) is chosen on the AI providers tab.

            4. MCP servers for n8n

            Add a remote MCP server (an https address). The panel saves its token inside n8n and builds a ready chat agent in n8n that uses it and your AI provider. The agent is created switched off: open it in n8n and use the Chat button.
