# Security policy

Please report vulnerabilities privately through GitHub: **Security -> Report a vulnerability** on this repository. Do not open a public issue for a security problem. Include what you found, how to reproduce it and the version (commit) you tested. You should get an answer within a week.

In scope: the panel (`console/`), the AI gateway (`llm-gate/`), the Hermes helper (`bridge/`) and the install and hardening scripts (`deploy/`). Hermes Agent and n8n themselves are separate projects: report their issues to them.

Never include real API keys, passwords or server addresses in a report; use placeholders.
